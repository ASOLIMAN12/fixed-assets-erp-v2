Assets Pro v3.9.0 — Web + Windows Shield
========================================

محتويات النسخة
--------------
1) حماية تطبيق الويب وقاعدة PostgreSQL كما في v3.8.0.
2) مركز حماية موحد للأدمن داخل security.html.
3) Windows Security Agent قابل للتثبيت من مجلد windows-agent.
4) ربط آمن لكل جهاز برمز يستخدم مرة واحدة وينتهي بعد 30 دقيقة.
5) مفتاح مستقل لكل جهاز محفوظ كبصمة في الخادم ومشفر بـ DPAPI في ويندوز.
6) إرسال حالة Defender وFirewall وBitLocker والتحديثات والدخول إلى لوحة الأدمن.

ترقية الويب على Render
----------------------
1) ارفع محتويات هذه الحزمة إلى مستودع fixed-assets-erp.
2) اترك Render ينفذ npm install ثم npm start.
3) لا تنشئ قاعدة جديدة؛ استخدم DATABASE_URL الحالية.
4) الجداول الجديدة للأجهزة والسجل الأمني تنشأ تلقائيًا عند تشغيل النسخة.
5) تأكد من وجود NODE_ENV=production وINITIAL_SETUP_KEY بطول 16 حرفًا أو أكثر.

تثبيت الحماية على ويندوز
-----------------------
1) افتح Assets Pro بعد اكتمال نشر v3.9.0 وسجل الدخول كـ Admin.
2) اضغط «مركز الحماية» ثم «إنشاء رمز ربط جهاز ويندوز».
3) على الجهاز المطلوب افتح windows-agent ثم شغّل Install-AssetsProSecurity.cmd.
4) أدخل رابط Assets Pro ورمز الربط الظاهر في الموقع.
5) بعد التثبيت افتح Assets Pro Security من قائمة Start.

ضوابط الأمان
------------
- لا تُرسل كلمة مرور الأدمن إلى تطبيق ويندوز.
- لا تُحفظ مفاتيح Render أو Resend أو PostgreSQL على الجهاز.
- لا يستقبل Windows Agent أوامر تنفيذ من الويب ولا يتيح Remote Control.
- الاتصال بالخادم عبر HTTPS فقط.
- إلغاء ربط الجهاز من مركز الحماية يبطل مفتاحه فورًا.
- التطبيق لا يحذف ملفات ولا يغيّر قواعد Firewall المخصصة؛ يضمن فقط تشغيل الملفات الثلاثة.
- حماية المجلدات من الفدية اختيارية لأنها قد تتطلب السماح لبعض البرامج الموثوقة.

حدود الاختبار
-------------
تم اختبار الواجهات الخلفية ودورة الربط والمفاتيح والصلاحيات آليًا. ملفات Windows
مبنية لـ Windows PowerShell 5.1 المضمن في Windows 10/11، ويجب إجراء أول تثبيت
فعلي على جهاز تجريبي قبل تعميمها على بقية أجهزة الشركة.
