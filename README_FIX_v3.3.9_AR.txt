Assets Pro Enterprise v3.3.9

إصلاح زر إعادة الاحتساب:
- الزر يستجيب دائمًا ويعرض رسالة واضحة عند وجود خطأ.
- إذا كانت الفترة مقفلة، يعرض خيار فك/فتح الفترة ثم متابعة إعادة الاحتساب.
- الإقفال المعتمد يحتاج صلاحية Admin لفكه.
- يتم أخذ Backup داخلي قبل إعادة الاحتساب.
- يتم حذف Snapshot تشغيل الإهلاك الحالي فقط بعد التأكيد ثم فتح معاينة احتساب جديدة.
- لا يتم حذف Snapshot الاعتماد التاريخي.
