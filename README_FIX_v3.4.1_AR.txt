Assets Pro v3.4.1 — إصلاح تفاصيل بطاقات المؤشرات

- إصلاح بطاقات شاشة الأصول بحيث تستخدم بيانات الأصول الفعلية بدل النافذة العامة الفارغة.
- إجمالي التكلفة / مجمع الإهلاك / صافي القيمة / الإهلاك الشهري تفتح جدول التفاصيل الحقيقي.
- عدد الأصول يفتح قائمة الأصول الفعلية.
- إعادة إظهار فلاتر وجدول نافذة التفاصيل عند كل فتح.
- بطاقات الإهلاك توجه إلى نتائج الإهلاك الفعلية حسب الحالة.
- الاحتفاظ بتحسينات الأداء الموجودة في v3.4.0.
