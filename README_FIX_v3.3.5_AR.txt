Assets Pro v3.3.5 — إصلاحات التشغيل
1) إقفال/فتح شهر الإهلاك يعمل فعليًا بعد وجود احتساب محفوظ.
2) معاينة وإعادة احتساب الإهلاك لا تقوم بتنزيل Backup تلقائيًا.
3) النسخ التلقائي قبل العمليات أصبح داخليًا فقط؛ تنزيل Backup يدوي من زر النسخة الاحتياطية.
4) بطاقات إهلاك الشهر ومجموع الإهلاك الشهري في لوحة التحكم تنقل مباشرة إلى شاشة الإهلاك.
5) الحفاظ على معادلة الإهلاك الحالية دون تغيير.
